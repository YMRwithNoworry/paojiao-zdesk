# ZSDesk

Windows 多标签文件管理器与桌面格子。可以在一个窗口里浏览多个文件夹、使用双栏整理文件，也可以把桌面文件分组收纳。

[下载安装](https://github.com/qiu7824/zsdesk/releases/latest) · [使用说明](docs/user-guide.md) · [更新日志](CHANGELOG.md) · [问题反馈](https://github.com/qiu7824/zsdesk/issues)

适用于 Windows 10 / 11，64 位。当前版本为 **0.4.0**，支持简体中文和英文界面。

English UI is available. Non-Chinese Windows systems use English by default. Choose **≡ → Language → English** to change the application language immediately. Each package includes `README.en.txt`.

## 选哪个版本

| 版本 | 适合谁 |
|---|---|
| **全量版** | 不确定如何选时使用，包含文件管理、网络访问和桌面格子 |
| 标准版 | 只需要文件管理、搜索和预览 |
| 网络版 | 标准版加 FTP、SFTP/SSH、网络驱动器 |
| 桌面版 | 标准版加桌面格子 |
| 主题版 | 全量功能，增加 Mica、亚克力和深浅色材质，配置独立 |
| 桌面盒子独立版 | 只整理桌面，不包含文件管理窗口与搜索 |

每个版本提供安装程序和便携 ZIP。普通用户选择名称含 `setup.exe` 的安装程序；便携版解压后运行 `ZSDesk.exe`，保留整个程序目录和 `data` 配置目录。

## 开始使用

1. 安装或解压后打开 ZSDesk，先用普通文件夹熟悉操作。
2. 按 **Ctrl+T** 新建标签，**Ctrl+L** 输入目录，**Ctrl+F** 搜索。
3. 在 **≡ → 布局** 开启双栏、调整标签位置和命令栏；两栏分别保留自己的目录与标签。
4. 需要替代系统文件管理器时，进入 **≡ → 系统集成 → 默认打开文件夹、磁盘和此电脑**；选择“不接管系统资源管理器”可恢复。
5. 含桌面功能的版本可从 **≡ → 桌面格子** 启动和管理格子。删除格子不会删除磁盘文件。

## 常用操作

| 操作 | 快捷键或入口 |
|---|---|
| 新建、关闭、恢复标签 | Ctrl+T / Ctrl+W / Ctrl+Shift+T |
| 标签栏 | 右键标签打开该标签的菜单，右键标签栏空白处关闭当前标签 |
| 在新标签打开文件夹 | 鼠标中键点击文件夹 |
| 后退、前进、上一级 | Alt+← / Alt+→ / Alt+↑，支持鼠标侧键 |
| 调整图标大小 | Ctrl+滚轮 |
| 快速预览 | 空格；右侧预览窗格用 Alt+P |
| 新窗口 | Ctrl+N |
| 双击空白处返回上一级 | 在“预览与操作”中开关 |
| 显示文件夹总大小并排序 | 排序 → 计算并按总大小排序 |
| 检查版本更新 | 关于 ZSDesk → 检查更新 |

## 搜索、预览和右键

- **搜索**：可选择自带搜索或 Everything；网络共享及已有映射网络目录使用限定目录遍历搜索。首次建立本地索引需要时间，可在搜索设置中查看引擎、索引就绪状态和范围。
- **预览**：内置预览与 QuickLook 可选择。Office 文档预览需要相应的已安装组件；图片、音视频格式取决于系统解码器。
- **右键**：支持经典系统菜单和 Windows 11 样式。Windows 11 样式按对象显示常用操作，可勾选首屏应用扩展。Shift+右键可直接使用经典菜单。
- **Listary**：安装和连接方式见[详细使用说明](docs/user-guide.md)及 `integrations/listary`。

## 0.4.0 更新

- 安装首页可展开“选择安装位置”，分别选择登录 Windows 时打开文件管理主窗口或启动桌面格子。各版本仅显示支持的选项，新装默认关闭，升级保留原设置。
- Windows 10 的“此电脑”恢复系统常用文件夹，左侧按根节点分组并提供“库”入口。文件视图使用系统状态栏显示项目数、选中数和视图切换按钮。
- 顶部和侧边标签均支持右键打开标签菜单，右键空白处关闭当前页。桌面格子首次显示即恢复已有成员。
- Windows 11 样式的右键菜单按需加载，支持管理应用扩展、文件类型命令及动态子菜单。关闭导航树、取消菜单或结束窗口会话时会释放相应资源。

完整变化见[更新日志](CHANGELOG.md)。

## 0.3.18 更新

- 右键顶部标签关闭所点页，右键标签栏空白处关闭当前页，Shift+右键打开标签菜单。

- “右键菜单 → 优先显示常用命令”可在加载扩展前显示常用操作，完整菜单仍可从末项打开。
- 快捷键列表支持滚轮和键盘翻页，搜索快捷键设置在当前面板打开。
- 内置搜索降低大结果集分页和索引快照的峰值内存。安装包和便携包含 Listary 6、7.0 的当前目录插件。

## 0.3.17 更新

- 增加英文界面和语言设置，修复网络文件夹搜索、剪切图标变浅及搜索后导航。
- 分离鼠标观察与桌面绘制，减少图标完成后的重复重绘，修复索引空闲释放，限制空闲菜单进程和文件窗口线程。
- 增加文件管理器托盘开关与右侧收藏夹宽度调整，改善任务栏分组、远程文件剪贴板及安装升级退出。

- 个别环境中当前标签难以辨认时，可开启“≡ → 布局 → 当前标签增强对比”；默认关闭，不改变既有主题，增强模式使用中性色轮廓而非蓝色短线。
- 地址栏支持在当前本地目录启动 `cmd`、`cmd.exe`；网络目录使用 PowerShell 或 pwsh。
- “接管新出现的系统浏览窗口”可以独立开启：不设为默认文件管理器时，仅在文件管理窗口打开期间生效，最后一个窗口关闭后停止。
- 改善 Win+E 按键与窗口激活时序，以及连续右键点击时的菜单准备行为。
- 启动时每天最多检查一次更新，可在“关于”中关闭；发现新版本后由用户决定下载。下载自动匹配版本类型并核对 SHA-256，安装版可启动安装程序，便携版打开已校验的 ZIP 后手动替换程序，保留 `data`。
- 包含文件选择窗口、上传文件夹识别与外部目录定位的修复。
- 原选择窗口具有额外选择动作或自定义确认下拉时，保留完整原生选择器及其回调。
- 桌面图标拖动时按可见窗口避让，历史布局中的不可见项目不占用落点；从格子拖出保留实际抓取点。
