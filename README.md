# ZSDesk

Windows 多标签文件管理器与桌面格子。可以在一个窗口里浏览多个文件夹、使用双栏整理文件，也可以把桌面文件分组收纳。

[下载安装](https://github.com/qiu7824/zsdesk/releases/latest) · [使用说明](docs/user-guide.md) · [更新日志](CHANGELOG.md) · [问题反馈](https://github.com/qiu7824/zsdesk/issues)

适用于 Windows 10 / 11，64 位。目前正式版为 **0.3.15**；主分支的待发布改进列在更新日志“未发布”中。

## 选哪个版本

| 版本 | 适合谁 |
|---|---|
| **全量版** | 不确定如何选时使用，包含文件管理、网络访问和桌面格子 |
| 标准版 | 只需要文件管理、搜索和预览 |
| 网络版 | 标准版加 FTP、SFTP/SSH、网络驱动器 |
| 桌面版 | 标准版加桌面格子 |
| 主题版 | 全量功能，增加 Mica、亚克力和深浅色材质，配置独立 |
| 桌面盒子独立版 | 只整理桌面，不包含文件管理窗口与搜索 |

每个版本提供安装程序和便携 ZIP。普通用户选择名称含 `setup.exe` 的安装程序；便携版解压后运行 `ZSDesk.exe`，保留整个程序目录和 `data` 配置目录。

## 开始使用

1. 安装或解压后打开 ZSDesk，先用普通文件夹熟悉操作。
2. 按 **Ctrl+T** 新建标签，**Ctrl+L** 输入目录，**Ctrl+F** 搜索。
3. 在 **≡ → 布局** 开启双栏、调整标签位置和命令栏；两栏分别保留自己的目录与标签。
4. 需要替代系统文件管理器时，进入 **≡ → 系统集成 → 默认打开文件夹、磁盘和此电脑**；选择“不接管系统资源管理器”可恢复。
5. 含桌面功能的版本可从 **≡ → 桌面格子** 启动和管理格子。删除格子不会删除磁盘文件。

## 常用操作

| 操作 | 快捷键或入口 |
|---|---|
| 新建、关闭、恢复标签 | Ctrl+T / Ctrl+W / Ctrl+Shift+T |
| 在新标签打开文件夹 | 鼠标中键点击文件夹 |
| 后退、前进、上一级 | Alt+← / Alt+→ / Alt+↑，支持鼠标侧键 |
| 调整图标大小 | Ctrl+滚轮 |
| 快速预览 | 空格；右侧预览窗格用 Alt+P |
| 新窗口 | Ctrl+N |
| 双击空白处返回上一级 | 在“预览与操作”中开关 |
| 显示文件夹总大小并排序 | 排序 → 计算并按总大小排序 |
| 检查版本更新 | 关于 ZSDesk → 检查更新 |

## 搜索、预览和右键

- **搜索**：可选择自带搜索或 Everything。首次建立索引需要时间；搜索没有结果时，先在搜索设置中查看引擎、索引就绪状态和搜索范围。
- **预览**：内置预览与 QuickLook 可选择。Office 文档预览需要相应的已安装组件；图片、音视频格式取决于系统解码器。
- **右键**：提供系统经典菜单、Windows 11 菜单和自绘样式。原生 Windows 11 菜单受系统组件版本影响；无法使用时可在设置中切换样式。
- **Listary**：安装和连接方式见[详细使用说明](docs/user-guide.md)及 `integrations/listary`。

## 主分支待发布改进

- 地址栏支持在当前本地目录启动 `cmd`、`cmd.exe`；网络目录使用 PowerShell 或 pwsh。
- “接管新出现的系统浏览窗口”可以独立开启：不设为默认文件管理器时，仅在文件管理窗口打开期间生效，最后一个窗口关闭后停止。
- 改善 Win+E 按键与窗口激活时序，以及连续右键点击时的菜单准备行为。
- 启动时每天最多检查一次更新，可在“关于”中关闭；发现新版本后由用户决定下载。下载自动匹配版本类型并核对 SHA-256，安装版可启动安装程序，便携版打开已校验的 ZIP 后手动替换程序，保留 `data`。
- 包含文件选择窗口、上传文件夹识别与外部目录定位的修复。
