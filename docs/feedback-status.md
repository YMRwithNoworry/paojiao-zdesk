# 兼容性与反馈状态

正式安装包：[v0.3.15](https://github.com/qiu7824/zsdesk/releases/tag/v0.3.15)。主分支未发布改进见[更新日志](../CHANGELOG.md)。

| 项目 | 代码或发布状态 | 验证范围 |
|---|---|---|
| 全屏右上角关闭按钮、屏幕上沿标签命中 | 0.3.15 已发布 | 保留高 DPI 与多显示器回归 |
| 地址栏 CMD | 主分支已支持本地工作目录 | 命令解析、参数隔离及网络路径边界 |
| 临时系统窗口接管 | 主分支已支持独立开关和窗口生命周期 | 多窗口配置合并、关闭最后窗口的策略 |
| Win+E 触发开始菜单 | 主分支已调整输入确认与窗口激活顺序 | Windows 11 23H2 反馈环境仍需实机复测 |
| 右键延迟与偶发无响应 | 0.3.14 包含手势和子菜单修复；主分支继续改进重复请求和等待反馈 | 原生菜单首次加载、不同扩展和系统版本需分别复测 |
| 手机 MTP 访问 | 已保留设备目录的 Shell 标识 | 仍需连接实际手机验证浏览、复制及返回上一级 |
| Git、SVN、VS Code 等右键扩展 | 0.3.12—0.3.14 包含命令参数及子菜单修复 | 仍需对应扩展版本与反馈环境验证 |
| 文件夹内搜索无结果 | 已改进范围更新及搜索引擎状态展示 | 需区分索引未就绪、范围限制及可重复的查询故障 |
| 自动更新 | 主分支支持检查、提示、匹配下载及校验 | 安装程序由用户启动；便携版保留手动替换 |
| 原生选择窗口的额外确认动作 | 检测到额外选择动作或确认下拉时保留原窗口 | 不重建或替代原回调；具体调用程序仍需验证 |
| 单入口、单窗口的文件与文件夹混合选择 | ZSDesk 混合返回流程尚未完成 | 需核对原窗口的选择能力及返回协议 |
| 桌面图标松手后偏离落点 | 已修正不可见历史项目占位与格子拖出抓取点 | 仍需本机实际拖动复测；诊断记录包含指针与最终落点 |
| 部分 Windows 10 环境难以辨认当前标签 | 提供默认关闭的“当前标签增强对比”兼容选项 | 内存渲染覆盖深浅色、失焦及多种 DPI；关闭时保持原像素，Win10 22H2 实机效果仍需确认 |

Issue 保持打开不等于相同故障在所有新版中仍可复现；只有明确的修复版本和复测结果才构成关闭依据。
